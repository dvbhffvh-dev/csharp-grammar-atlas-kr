## 1. 반복을 만들기 전에 세 가지를 정하세요

반복문은 비슷한 명령을 여러 번 실행합니다.
복사한 문장을 길게 나열하는 대신 규칙을 코드로 표현합니다.
먼저 **어디서 시작하는지**, **언제 계속하는지**, **무엇이 바뀌는지**를 정하세요.
조건이 언젠가 false가 되는 이유를 설명할 수 있어야 합니다.

예를 들어 1부터 5까지 합하려면 현재 수는 1에서 시작합니다.
현재 수가 5 이하인 동안 반복합니다.
매번 합계에 현재 수를 더하고 현재 수를 1 증가시킵니다.
이 설명을 그대로 for 문에 대응시킬 수 있습니다.

## 2. 실습 1 — for의 실행 순서

[Program.cs](Program.cs)의 첫 블록은 1부터 5까지 누적합니다.

```csharp
int sum = 0;
for (int number = 1; number <= 5; number++)
{
    sum += number;
}
```

실행 순서는 초기화 → 조건 → 본문 → 증감 → 조건입니다.
초기화는 반복 시작 전에 한 번만 실행합니다.
조건은 본문에 들어갈 때마다 검사합니다.
증감은 본문이 끝난 뒤 다음 조건 검사 전에 실행합니다.

| 회차 | number | 더하기 전 sum | 더한 후 sum |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 1 |
| 2 | 2 | 1 | 3 |
| 3 | 3 | 3 | 6 |
| 4 | 4 | 6 | 10 |
| 5 | 5 | 10 | 15 |

그 다음 number는 6이 되고 6 <= 5가 false라 종료합니다.
sum을 반복문 안에서 매번 0으로 만들면 이전 누적값을 잃습니다.
누적 변수와 회차별 임시 변수를 어느 블록에 선언할지 구별하세요.
for 선언부의 number는 일반적으로 그 for 범위 밖에서 사용할 수 없습니다.

## 3. 실습 2 — while과 do-while

while은 조건이 true인 동안 본문을 반복합니다.
처음부터 false이면 한 번도 실행하지 않습니다.

```csharp
int remaining = 3;
while (remaining > 0)
{
    Console.WriteLine(remaining);
    remaining--;
}
```

1. 3 > 0이므로 3을 출력하고 2로 줄입니다.
2. 다음 회차에서 2를 출력하고 1로 줄입니다.
3. 1을 출력한 뒤 0이 되어 종료합니다.

remaining--를 빼면 조건이 계속 true라 끝나지 않습니다.
반복 횟수보다 어떤 상태가 유지되는 동안 작업한다는 의미일 때 while이 잘 맞습니다.
입력을 계속 받는 메뉴 등에서도 종료 조건을 먼저 설계해야 합니다.

do-while은 본문 실행 후 조건을 검사합니다.
그래서 최소 한 번 실행됩니다.
구문 끝에 세미콜론이 붙는 점도 확인하세요.

```csharp
int attempts = 0;
do
{
    attempts++;
}
while (attempts < 1);
```

예제는 첫 실행에서 attempts가 1이 된 뒤 조건이 false라 끝납니다.
초기 상태를 바꿔도 먼저 실행된다는 성질이 유지됩니다.
반드시 한 번 수행해야 하는 작업인지 요구사항으로 판단하세요.

## 4. 실습 3 — continue와 break

continue는 현재 회차의 남은 본문을 건너뛰고 다음 회차로 이동합니다.
break는 가장 가까운 반복문 전체를 종료합니다.
둘 모두 반복문을 벗어난 이후 코드까지 끝내는 return과는 다릅니다.

[Program.cs](Program.cs)는 1부터 10을 살펴보되 8에서 멈춥니다.
홀수는 continue로 건너뛰고 짝수만 더합니다.

1. 1은 홀수여서 합산을 건너뜁니다.
2. 2, 4, 6만 합산합니다.
3. 8을 만나는 순간 break가 먼저 실행됩니다.
4. 따라서 8은 합에 들어가지 않고 결과는 12입니다.

```csharp
if (number == 8)
{
    break;
}
if (number % 2 != 0)
{
    continue;
}
selectedSum += number;
```

for에서 continue를 만나도 증감 구문은 실행된 뒤 다음 조건을 검사합니다.
while에서는 본문에 있던 상태 갱신을 continue가 건너뛸 수 있습니다.
그 경우 종료 조건에 필요한 값이 바뀌지 않아 무한 반복이 될 수 있으니 특히 주의하세요.

## 5. 실습 4 — foreach와 중첩 반복

배열 요소를 순서대로 읽을 때는 foreach가 간결합니다.

```csharp
foreach (string topic in topics)
{
    Console.WriteLine($"복습: {topic}");
}
```

topics에서 요소 하나를 받아 topic으로 사용하고 다음 요소로 이동합니다.
인덱스 계산이나 끝 범위를 직접 관리할 필요가 없습니다.
배열을 어떻게 생성하는지는 다음 단원에서 자세히 다룹니다.

일반적인 foreach 반복 변수에 새 값을 대입해 배열 요소를 교체할 수는 없습니다.
인덱스가 필요하거나 배열 요소를 직접 바꾸려면 for가 적합할 수 있습니다.
참조 타입 요소가 가리키는 객체의 내부 변경은 별개의 문제이며 09단원에서 이어집니다.

중첩 반복은 바깥 회차 한 번마다 안쪽 반복을 처음부터 끝까지 실행합니다.
예제는 row가 1~2, column이 1~3이라 총 6개 값을 출력합니다.
각 행에서 곱을 출력하고 안쪽 반복이 끝나면 줄을 바꿉니다.

바깥이 n회이고 안쪽이 m회면 본문은 보통 n × m회 실행됩니다.
입력 크기가 커질 때 실행량이 빠르게 커질 수 있으므로 무심코 반복을 중첩하지 마세요.
안쪽의 break는 안쪽 반복만 끝내며 바깥까지 자동 종료하지 않습니다.

## 6. 경계값을 확인하는 방법

반복 횟수가 0, 1, 여러 번일 때를 각각 생각해 보세요.
빈 배열에서도 동작하는지, 첫 값과 마지막 값이 포함되는지 확인합니다.
`i < length`와 `i <= length`의 차이는 배열 접근에서 특히 중요합니다.
인덱스 0부터 시작하는 길이 3의 배열은 0, 1, 2에만 접근합니다.

디버거에서는 반복 본문에 중단점을 놓고 한 단계씩 진행할 수 있습니다.
number와 sum의 값을 표처럼 적어 예상과 실제를 비교하세요.
전체 코드를 한꺼번에 바라보는 것보다 한 회차의 상태 변화를 추적하는 것이 효과적입니다.

## 7. 자주 하는 실수

- 누적 변수를 본문 안에서 초기화: 이전 회차의 결과를 잃습니다.
- 종료 상태 갱신 누락: 조건이 계속 true여서 끝나지 않습니다.
- continue 전에 필요한 갱신 생략: while에서 무한 반복을 만들 수 있습니다.
- break가 모든 중첩 반복을 종료한다고 생각: 가장 가까운 대상만 종료합니다.
- 반복 끝의 범위 하나 더 포함: 실제로 처리할 첫 값과 마지막 값을 적어 보세요.

<summary>정답</summary>
