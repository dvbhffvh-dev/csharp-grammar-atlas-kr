## 1. 같은 종류의 값들을 한곳에 모으기

학생 점수가 세 개라면 score1, score2, score3이라는 변수를 만들 수 있습니다.
하지만 학생이 수백 명이면 개별 이름으로 관리하기 어렵습니다.
배열은 같은 요소 타입의 값을 정해진 개수만큼 모아 놓고 위치로 접근하게 합니다.
int[]는 int 요소를 가진 배열 타입입니다.

```csharp
int[] scores = { 80, 90, 100 };
int first = scores[0];
scores[1] = 95;
```

대괄호 안의 숫자는 인덱스입니다.
첫 요소의 인덱스는 0이며 마지막 인덱스는 Length - 1입니다.
길이 3의 배열에서 유효한 인덱스는 0, 1, 2입니다.
scores[3]은 네 번째 요소를 요청하므로 범위를 벗어납니다.

배열 인스턴스의 길이는 생성 후 바꿀 수 없습니다.
더 많은 공간이 필요하면 새 배열을 만들거나 크기 조정용 컬렉션을 사용합니다.
Array.Resize도 기존 인스턴스 자체를 늘리는 개념이 아니라 필요하면 다른 배열을 만들어 참조를 바꿉니다.
List<T> 같은 컬렉션은 이후 단원에서 배웁니다.

## 2. 실습 1 — 합과 평균을 계산하기

[Program.cs](Program.cs)의 첫 예제는 세 점수를 순회합니다.

```csharp
int sum = 0;
for (int i = 0; i < scores.Length; i++)
{
    sum += scores[i];
}
double average = (double)sum / scores.Length;
```

1. i는 0에서 시작해 첫 점수 80을 읽습니다.
2. i가 1, 2일 때 90과 100을 더합니다.
3. i가 3이 되면 3 < 3이 false라 종료합니다.
4. 합계 270을 double로 바꾼 뒤 길이 3으로 나누어 평균 90.0을 만듭니다.

배열의 크기를 코드에 숫자로 중복 작성하지 않고 Length를 사용합니다.
요소가 추가되더라도 순회 범위를 함께 수정할 필요가 줄어듭니다.
예제는 점수가 세 개라는 전제가 있지만 일반 평균 함수에서는 빈 배열도 처리해야 합니다.
길이가 0이면 무엇을 반환할지, 예외를 던질지 등의 정책을 먼저 정하세요.

`scores[^1]`은 뒤에서 첫 번째, 즉 마지막 요소입니다.
인덱스와 범위 문법은 C# 8부터 지원됩니다.
`^0`은 마지막 요소가 아니라 끝 다음 위치를 뜻하므로 요소 접근에 쓰면 범위를 벗어납니다.

## 3. 실습 2 — 기본값과 배열 복사

`new int[3]`은 int 요소 세 개를 0으로 초기화합니다.
지역 변수를 선언만 하고 읽는 규칙과 다르게 배열 요소에는 기본값이 적용됩니다.
bool 요소는 false, 참조 타입 요소는 null이 기본값입니다.

```csharp
int[] empty = new int[3];
string?[] names = new string?[3];
```

names에는 아직 실제 문자열이 들어 있지 않습니다.
새 string 배열의 모든 요소에 자동으로 빈 문자열이 들어간다고 생각하면 안 됩니다.
nullable 표기는 의도를 드러내지만 배열 공간을 실제 문자열로 채워 주지는 않습니다.

[Program.cs](Program.cs)는 Clone으로 int 배열을 복사합니다.

```csharp
int[] copied = (int[])scores.Clone();
copied[0] = 50;
```

1. Clone은 길이와 요소 값을 복사한 새 배열을 만듭니다.
2. 반환 타입이 object이므로 int[] 캐스트로 받습니다.
3. 복사본의 첫 요소를 50으로 바꿉니다.
4. 원본의 첫 요소는 80으로 유지됩니다.

`int[] copied = scores;`만 쓰면 배열이 복제되지 않습니다.
두 변수가 같은 배열을 가리키므로 한쪽을 통해 바꾼 요소가 다른 쪽에도 보입니다.
09단원에서 참조의 복사와 객체의 복사를 그림으로 더 자세히 배웁니다.

Clone은 얕은 복사입니다.
int 배열에서는 요소 값이 복사되지만, 객체 참조 배열에서는 참조가 복사되어 내부 객체를 공유할 수 있습니다.
새 배열을 만들었다고 그 안의 모든 객체까지 별도로 복제되었다고 생각하지 마세요.

## 4. 실습 3 — 직사각형 다차원 배열

행과 열이 있는 표에는 int[,]를 사용할 수 있습니다.
쉼표 하나는 두 차원의 배열을 나타냅니다.

```csharp
int[,] grid =
{
    { 1, 2, 3 },
    { 4, 5, 6 }
};
```

행 2개, 열 3개이며 전체 요소는 6개입니다.
`grid[1, 2]`는 두 번째 행, 세 번째 열의 값 6입니다.
각 차원도 인덱스 0부터 시작합니다.

Length는 전체 요소 수 6을 반환합니다.
GetLength(0)은 첫 차원의 길이 2, GetLength(1)은 두 번째 차원의 길이 3입니다.
배열 순회에서는 어떤 차원의 범위를 검사하는지 구별해야 합니다.

```csharp
for (int row = 0; row < grid.GetLength(0); row++)
{
    for (int column = 0; column < grid.GetLength(1); column++)
    {
        Console.WriteLine(grid[row, column]);
    }
}
```

바깥에서 행, 안쪽에서 열을 이동하면 같은 행의 값을 차례로 처리합니다.
좌표를 (row, column) 순으로 정했다면 이름과 모든 접근에서 일관되게 유지하세요.
x/y와 행/열 표기를 섞으면 문법은 맞아도 잘못된 위치를 읽을 수 있습니다.

## 5. 실습 4 — 가변 배열

int[][]는 int 배열들을 요소로 가지는 배열입니다.
각 내부 배열은 길이가 달라도 됩니다.
여러 학생이 서로 다른 수의 시험을 치른 경우처럼 행마다 길이가 다른 데이터에 맞습니다.

```csharp
int[][] rows =
{
    new[] { 10, 20 },
    new[] { 30, 40, 50 }
};
```

1. 바깥 배열 길이는 2입니다.
2. rows[0]은 길이 2의 내부 배열입니다.
3. rows[1]은 길이 3의 내부 배열입니다.
4. rows[1][2]는 두 번째 배열의 세 번째 값 50입니다.

`new int[3][]`은 내부 배열 세 개까지 자동 생성하지 않습니다.
바깥 배열의 각 요소는 처음에 null이므로 각 행을 별도로 초기화해야 합니다.
내부 배열이 없을 수 있는 구조라면 null 허용 여부도 타입과 검사에 반영하세요.

| 비교 | 직사각형 배열 | 가변 배열 |
| --- | --- | --- |
| 타입 | int[,] | int[][] |
| 접근 | grid[row, column] | rows[row][column] |
| 행 길이 | 같은 열 길이 | 행마다 다를 수 있음 |
| 전체 Length | 전체 요소 수 | 바깥 배열의 요소 수 |

## 6. 범위로 부분 배열 만들기

예제의 `scores[1..]`는 인덱스 1부터 끝까지를 선택합니다.
일반 배열에서 이 표현은 선택한 요소를 새 배열로 복사합니다.
따라서 결과는 90, 100입니다.

`scores[1..3]`에서 끝 인덱스 3은 포함되지 않습니다.
시작 포함, 끝 제외 규칙은 길이 계산을 쉽게 만듭니다.
범위가 잘못되면 예외가 발생하므로 입력으로 받은 인덱스는 검증하세요.
배열 슬라이스와 Span 같은 메모리 뷰는 동작이 다르며 여기서는 새 배열이라는 점에 집중합니다.

## 7. 자주 하는 실수

- `i <= scores.Length`: 마지막 회차에 범위를 벗어납니다. 보통 <를 사용합니다.
- 빈 배열에서 scores[0] 읽기: 먼저 길이가 양수인지 확인하세요.
- int[,]의 Length를 행 수로 사용: 전체 요소 수이므로 GetLength를 사용하세요.
- int[][] 생성 후 내부 배열 누락: 바깥 요소의 null 상태를 처리해야 합니다.
- 단순 대입을 깊은 복사로 이해: 배열 참조와 요소 객체의 공유를 구별하세요.
